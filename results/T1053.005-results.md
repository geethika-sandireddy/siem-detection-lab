# T1053.005 — Scheduled Task/Job: Scheduled Task

**Victim:** Windows 10.

## Atomic test used

```powershell
Invoke-AtomicTest T1053.005 -TestNumbers 1
```

Creates a scheduled task via `schtasks.exe /Create` that runs a benign
command at a fixed time — the classic "run again after reboot" persistence
pattern.

```
Invoke-AtomicTest T1053.005 -TestNumbers 1 -Cleanup
```
was run afterward to remove the task.

## What showed up in Wazuh

Two log sources again:

- **Windows Security Event ID 4698** ("A scheduled task was created") —
  requires the "Audit Other Object Access Events" advanced audit policy to
  be enabled; off by default, so this had to be turned on explicitly via
  `auditpol.exe`.
- **Sysmon Event ID 1** — `schtasks.exe` process creation with the full
  `/Create /TN ... /TR ...` command line, including the task's target
  command.
